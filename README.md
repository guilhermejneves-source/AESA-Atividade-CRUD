## 📌 Sobre o Projeto
Mini aplicação Java para gerenciamento de tarefas via terminal. O projeto utiliza o padrão arquitetural MVC simplificado (Model, Service, App).

## 🛠️️ Estrutura de Dados Escolhida
**ArrayList<Tarefa>**
A escolha do `ArrayList` baseia-se na necessidade de manter a ordem sequencial de inserção das tarefas e na eficiência para iterar sobre os dados (Listar Todos). Embora as operações de busca por ID tenham complexidade de tempo **O(n)** (necessitando percorrer o vetor), a estrutura oferece excelente legibilidade e flexibilidade para este cenário.

## ▶️ Como Executar
1. Clone este repositório.
2. Navegue até o pacote `br.edu.aesa.app` e execute a classe `Main.java`.
3. Siga as instruções do menu interativo no terminal.
